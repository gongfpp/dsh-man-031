## 当前架构：仅离线素材播放

0.5.0 移除了 0.4.0 的在线合成、凭据设置、每日额度、缓存服务和 `man031_voice_prepare` 工具。最终用户不提供 Key；运行包不含语音云服务调用代码。开发时的生成脚本、调用台账与原始文件只保存在不发布的 scripts/dev 中。

55 份预制 WAV（0.6.0 新增 18 份）包含台词前缀、数字 0–19、整十数、point、hundred/thousand/million/billion，以及人民币/美元单位与结尾。manifest 显式声明资源，宿主只提供这些文件，不开放目录。数字内容经本地缓存识别模型校验；这不能代替主观音质验收。每份新片段的人工听审字段保留 false，不把用户认可的整句扩大成全部素材已听审。

生成脚本：`generate-doubao-offline.mjs`。渲染脚本：`render-doubao-offline-pilot.mjs`。发布脚本：`publish-doubao-offline.mjs`。所有调用仅发生在开发阶段，使用现有音色；不新建音色、不调用付费云识别。单词各自完整合成，不在词中切割；只修剪外围低能量静音并保留 50ms 余量，静态增益统一活动帧 RMS 约 -24.8dB，true-peak 上限 -2.2dB，不变速或变调。

用户确认的 0.31 元整句保持原样：SHA-256 `616c0da0c19a87c82f8531cc8ee2aea1da87c2eb24c9506b72dfed44d9f4c1a2`。资源仍原样保留，但只有句子 ID 匹配时才能使用，不能替代十句中的另一句。0.6.0 按用户新要求，将显示及数字分词统一为三位小数四舍五入：从完整十进制文本提取千分位与下一位，用 BigInt 进位，避免浮点乘法边界错误；原费用记录不变。支持 0 至小于 1e12 的费用，较小正数按相同规则显示为 0.000。自动提醒随机一次、重试固定本次句子；试听可显式选十句之一。新素材生成与发布脚本为 generate-doubao-phrases.mjs / publish-doubao-phrases.mjs；本地识别报告、真实界面选句及 0.000749→0.001 播放证据位于 dev/doubao-phrases-v2。

## 费用与生命周期

投影 `man031Completion` 使用 stateVersion 2，配对 turn/start 与 completed turn/end。客户端只订阅宿主结果，不重新扫描历史。authenticated GET `/api/man-031/cost` 校验主会话本轮边界，再调用 costMeter 的 getTurnCost(sessionId,startSeq,endSeq,currency)。

只采信 apiCost 与完整定价覆盖；cost 中的套餐等价值不视作额外扣费。未知、缺失或不一致返回 unknown，不使用固定金额或硬编码汇率，也不混入无法精确归属的子任务费用。

客户端使用真实 React StrictMode 测试首轮、历史、绑定就绪、费用重试、跨窗口去重、取消与资源回收。关闭、切走、切换会话后不迟到播放。模拟时间轴和本地识别不能替代真实浏览器试听或实际轮次结束的验收；应分别记录验证结果。

## 小米 100 条候选集

`generate-mimo-100.mjs` 仅用于开发，按用户选择为 0.01–1.00 元各生成一条完整句，统一参考已认可的豆包 AI 成品。使用普通 MiMo TTS，不用收费 Batch 和云端 ASR。原计划 100 次调用；第 8 次 HTTP 200 但响应失败、未收到本地音频，保留失败台账并明确补生成一次，总尝试上限改为 101，已成功的 7 条不会重跑；输出、调用台账及勾选试听页位于被忽略的 dev 目录。整句仅调节音量，不拼贴、变速或改调。候选不自动写入运行 manifest，须由用户挑选。
