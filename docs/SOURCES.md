# 素材说明

当前声音全部由豆包预先合成，使用同一复刻音色。复刻参考为用户选定的 AI 合成 B 成品，不是真人原录音。运行包保留用户听审通过的 0.31 元原样整句；其他金额用新预制的台词、数字、单位与结尾在本地拼接，不混入下述原片或旧 MiMo 音频。新数字有本地识别核查，但不冒称所有组合均已人工听审。

已确认整句通过[官方体验中心](https://console.volcengine.com/speech/new/experience/tts?projectName=default)生成，新词库由开发者使用同一已分配音色经官方公共 API 预先生成；最终用户播放不调用该 API。适用[声音复刻协议](https://www.volcengine.com/docs/6561/1136414)。免费网页体验本身不代表可公开分发。2026-11-11，项目维护者确认现有照片和豆包音频已有覆盖本次公开发布的授权或其他适用许可，并要求发布完整插件；此确认仅针对本项目自身的发布行为，不等于向其他人授予商用、转许可或任意再分发权，照片与音频也不在 MIT 授权范围内（见 [LICENSE](../LICENSE) 与 [THIRD-PARTY-NOTICES.md](../THIRD-PARTY-NOTICES.md)）。人物照片的权利链未随项目移交：本项目不持有该照片、科比肖像或其遗产、以及图中品牌的任何权利，权利人提出异议时移除该图并退回纯文字提示。

## 公开价格与 Token 语音

0.8.0 的三份 Token 固定片段（开头、token、tokens）使用同一豆包音色预先生成，复用已有数字及结尾组成四套句式，不引入用户端合成。仅作整段静态增益和外围静音修剪；未冒称新片段或全部组合已通过人工听审。
